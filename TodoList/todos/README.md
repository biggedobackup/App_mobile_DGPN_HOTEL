# 📁 Dossier des TODOs Individuels

Ce dossier contient les fichiers de suivi de chaque modification effectuée
via le skill `clean-arch-mobile`.

## Convention de Nommage
```
TODO_<YYYY-MM-DD>_<HHmmss>.md
```

## Statuts Possibles
| Icône | Statut | Description |
|---|---|---|
| 🔄 | EN COURS | Le pipeline est en cours d'exécution |
| ✅ | TERMINÉ | Modification validée et vérifiée sans problème |
| ⚠️ | PARTIEL | Validé mais avec des avertissements ou intervention manuelle |
| ❌ | ÉCHOUÉ | Échec non résolu automatiquement |

---

> Les fichiers sont créés automatiquement par l'agent `todo_manager`.
> Ne pas modifier manuellement.
